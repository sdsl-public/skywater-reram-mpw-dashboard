# SkyWater ReRAM MPW Dashboard

SkyWater ReRAM MPW 프로젝트의 공개용 현황판 저장소입니다.

## 운영 방식

- 프로젝트 업무는 GitHub Issues에서 관리합니다.
- GitHub Pages는 공개용 읽기 전용 현황판으로 사용합니다.
- 현재 저장소를 초기화한 상태이며, 현황판 소스 업로드와 Pages 배포는 아직 완료되지 않았습니다.

## 공개 정보 주의사항

이 저장소와 Issues는 공개됩니다. PDK 파일, 비공개 회로 설계, 인증 정보, 미공개 연구 결과 및 NDA 적용 자료를 업로드하지 마세요.
