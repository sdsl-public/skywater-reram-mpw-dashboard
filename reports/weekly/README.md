# Weekly Report submissions

1. Complete the browser-based **Weekly Report** template from your dashboard.
2. Download the finished HTML file.
3. Upload into `reports/weekly/YYYY-MM/` (e.g. `reports/weekly/2026-10/`).
4. Commit to the new repository's `main` branch.
5. After the next GitHub Pages build, up to eight recent reports appear as
   safe read-only pages on the dashboard.

The monthly folders may contain a `.gitkeep` file to keep otherwise empty
folders tracked by Git.

**Public warning:** HTML reports uploaded to a public repository are public,
even if the Pages renderer strips scripts. Do not upload private research data.
