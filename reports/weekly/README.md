# Weekly Report 제출 안내

SkyWater ReRAM MPW 대시보드의 **리포트 생성** 버튼을 눌러 Weekly Report를 작성한 다음, **HTML 저장**으로 내려받은 파일을 이 폴더에 업로드합니다.

## 제출 절차

1. [리포트 작성 양식](https://sdsl-public.github.io/skywater-reram-mpw-dashboard/skywater_weekly_report_template.html)에서 필수 항목을 작성합니다.
2. HTML 저장 버튼으로 파일을 내려받습니다.
3. `reports/weekly/` 아래에 필요하면 연도 폴더(예: `2026/`)를 만들고 내려받은 **작성 완료 HTML 파일**을 업로드합니다.
4. GitHub의 변경 사항을 `main`에 반영하면 다음 Pages 배포에서 대시보드의 **최근 리포트 업데이트** 목록이 자동 갱신됩니다. 최근 변경된 3개 보고서가 표시되며, 항목을 누르면 GitHub 저장소의 원본 파일을 확인할 수 있습니다.

**공개 주의:** 이 저장소와 최근 업데이트 목록은 모두 공개됩니다. PDK 원본, 접근 자격정보, 비공개 회로도, 미공개 연구결과 등 민감한 자료를 업로드하지 마세요. 대시보드는 리포트 원본 HTML을 자동 실행하거나 GitHub Pages에 직접 게시하지 않고, 안전하게 GitHub 파일 화면으로 링크합니다.
